## 3. Known gaps

- **F6 – Categories:** TC-10 (`categories.test.ts`, "reassign … writes history") still fails deterministically as of P20. Likely cause is a test bug: the `moved` query is not scoped to the test user, so `moved[0]` can be another user's transaction on the same shared default category.
- **F13 – Export:** PNG/image export (`ExportPngButton.tsx`) has no unit or E2E test. Only PDF export is tested.
- **F21 – Anomaly/duplicate:** the TC-24 integration test (`anomaly.test.ts`) still fails as of P20, including when run on its own. TC-25 was flaky in P18.
- **F23 – Chatbot:** only unit-tested. Never checked with real Tawk.to credentials, including whether the CSP allows everything the widget needs.
- **F24 – Sitemap:** the page, route and footer link exist, but no test covers them (the spec expected an E2E test).
- **N5 – Performance:** k6 load tests never run. The initial JS bundle is 218 KB gzip, over the 200 KB budget (`docs/perf.md` §3).
- **N7 – Security:** `cc_app` still has UPDATE/DELETE on `audit_logs`/`transaction_history` (spec §6.1 requires INSERT/SELECT only). `lib/crypto.ts` has no key rotation (no keyring).
- **N8 – Availability:** the uptime monitor, 15-minute binlog cron and monthly restore drill are documented but not verified.
- **N9 – Compatibility:** the Firefox and WebKit Playwright projects are configured but have never been run.
