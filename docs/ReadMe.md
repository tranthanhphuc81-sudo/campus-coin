# CampusCoin – Quick Start for Evaluators

## What is CampusCoin?

CampusCoin ("Smart Spending, Student Style") is a full-stack, responsive web application that helps college students track income and expenses, set budgets, categorize spending, and receive AI-powered monthly insights and personalized saving tips. The app runs on modern web standards (React 19, Node.js 24 LTS, MySQL 8.4, Docker) and includes an admin portal for managing system data and monitoring usage.

## Key Assumptions

- **Users are college students** with USD or VND currency preference and Asia/Ho_Chi_Minh timezone as defaults (user-configurable).
- **AI recommendations are advisory only**, not certified financial advice; they are powered by a pluggable AI adapter (Google Gemini Flash by default, with OpenAI as an alternative).
- **No real bank integration or payment processing** — this is a learning/demo app for tracking and analysis only.
- **Data is CSV-importable** for quick onboarding (sample CSV files provided in `docs/samples/`).
- **Admin functions are gated behind TOTP MFA** to prevent unauthorized system changes.

## Quickest Way to Run It

For a full installation guide with Docker, manual, and production paths, see **`docs/INSTALL.md`**.

### Docker Quick Start (5 minutes)

```powershell
# 1. Clone and prepare
git clone <repo-url> CampusCoin
cd CampusCoin
Copy-Item .env.example .env
npm run keys:generate  # Copy output to .env

# 2. Start services
npm install
docker compose up -d
docker compose ps  # Wait for "healthy" status

# 3. Initialize database
npm run db:migrate -w backend
npm run db:seed -w backend -- --demo

# 4. Run the app
npm run dev
```

Open http://localhost:5174 in your browser. Demo TOTP code is printed to the console.

**For Bash (macOS/Linux):**
```bash
git clone <repo-url> CampusCoin
cd CampusCoin
cp .env.example .env
npm run keys:generate
npm install
docker compose up -d && docker compose ps
npm run db:migrate -w backend
npm run db:seed -w backend -- --demo
npm run dev
```

## Running Tests

```powershell
npm run lint           # ESLint
npm run typecheck      # TypeScript strict
npm test               # Unit and integration tests (both apps)
npm run test:e2e       # End-to-end tests with Playwright
npm run test:all       # All of the above in sequence
```

## Verification Checklist

- [ ] Docker containers are running: `docker compose ps`
- [ ] API health: `curl http://localhost:3000/api/v1/health/live` (returns 200)
- [ ] Web app loads: http://localhost:5174
- [ ] Admin login at `/admin/login` with demo credentials
- [ ] Student login at `/` with demo credentials
- [ ] API Swagger docs at `/api/v1/docs` (non-production only)
